01 / Identity

研究先于答案。

镜月研究部（Miroon Research）是 Miroon Studio 旗下的前沿计算机研究部门。我们关注那些尚无标准答案、却值得被严谨描述的问题。

Research 负责提出问题、建立证据与公开研究边界；当成果足够成熟时，Studio 可以为其提供工程支持与产品化能力。两者共享价值判断，但承担不同阶段的责任。

02 / Scope

面向前沿计算机研究。

我们从网络隐私与匿名通信出发，也关注安全、分布式系统及其相邻问题。研究范围由真实问题推动，而不是被固定标签限制。

01 / NETWORK

网络与隐私

考察通信关系、可观察信息与网络条件如何共同影响隐私。

02 / SYSTEM

系统与结构

研究去中心化、动态参与和不稳定条件下的系统行为。

03 / SECURITY

安全与边界

明确威胁、假设与结论边界，不把愿景写成已经成立的保证。

04 / EVIDENCE

实验与复核

让模型、原型与实验共同形成可检查、可重复的证据链。

04 / Method

从问题到可复核证据。

研究过程并不以漂亮结论为目标，而以每一步是否能够被解释、检查和重做为标准。

  1. 01问题

    先界定真正需要回答的研究问题。

  2. 02假设

    把依赖条件写出来，让结论不越过前提。

  3. 03模型

    将对象、环境与对手能力转换为可分析描述。

  4. 04实验

    用原型和实验检验模型能够解释什么。

  5. 05复核

    主动寻找反例、限制和无法覆盖的情况。

  6. 06公开

    只在材料成熟时发布足以被他人验证的版本。

05 / Principles

自由，但不逃避责任。

探索可以激进，表述必须克制。我们用五条原则约束研究，也用它们判断何时应该保持沉默。

01自由
02责任
03可验证
04极客
05务实

尚未验证的内容会被明确标记。尚未准备公开的材料不会因为页面需要“看起来完整”而被提前放出。
